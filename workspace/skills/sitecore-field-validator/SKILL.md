# Field Validator

Validate component fields against per-component documentation before MCP authoring calls.

## When to Use

**BEFORE** every `marketer_add_component_on_page` call:
- Check proposed fields against the component's documentation file
- Remove invalid fields
- Warn about removals

## Data Source

Per-component documentation files generated by `/generator-component-docs`:

```
.claude/skills/sitecore-component-docs/references/{Category}/{ComponentName}/{ComponentName}.md
```

## Process

### 1. Find and Read Component Documentation

```bash
# Find the doc file
Glob(pattern: ".claude/skills/sitecore-component-docs/references/**/{ComponentName}/{ComponentName}.md")

# Read the Fields table (within first ~40 lines)
Read(file_path: "{matched_path}", limit: 40)
```

### 2. Extract Field Table

Parse the Fields table from the documentation:
```markdown
| Field Name | Sitecore Type | Required | Description | Validation/Constraints |
|------------|---------------|----------|-------------|------------------------|
| heading | Single-Line Text | Yes | ... | ... |
| body | Rich Text | No | ... | ... |
```

Valid fields: `heading`, `body`

### 3. Compare Provided Fields

```javascript
// User provides: { heading: "Title", subheading: "Subtitle", body: "..." }
// Doc has: heading, body
// Invalid: subheading
// → Remove subheading, warn user
```

### 4. Return Validated Fields

```javascript
// Return: { heading: "Title", body: "..." }
// Warning: "CardGrid doesn't have 'subheading' field - removed"
```

## Integration with sitecore-author

Add validation step before authoring:

```
Step 2a: Validate Fields
├─ Glob for {ComponentName}/{ComponentName}.md doc file
├─ Read component's Fields table (first 40 lines)
├─ Compare provided fields against documented fields
├─ Remove invalid fields
└─ Warn about removals

Step 3: Add Component
└─ Call marketer_add_component_on_page with validated fields
```

## Example: Prevented Error

```javascript
// Without validation:
add_component_on_page({
  componentRenderingId: "e78b588a-...",
  fields: { heading: "Content", subheading: "Explore" }
});
// ERROR: Cannot find field 'subheading'

// With validation:
// 1. Glob for CardGrid/CardGrid.md → found
// 2. Read Fields table → CardGrid only has 'heading'
// 3. Remove 'subheading'
// 4. Warn: "CardGrid doesn't support 'subheading'"
// 5. Call MCP with { heading: "Content" }
// SUCCESS
```

## Field Type Reference

| Type | Description | Example |
|:-----|:------------|:--------|
| Single-Line Text | Plain text | "Welcome" |
| Rich Text | HTML content | "<p>Body text</p>" |
| Image | Image reference | (handled by sitecore-author-image) |
| General Link | Link with attributes | (handled by sitecore-author-link) |

## Common Validation Cases

| Component | Common Error | Solution |
|:----------|:-------------|:---------|
| CardGrid | Has `subheading` | Remove - only has `heading` |
| Button | Has `text` or `label` | Remove - only has `link` |
| Card | Missing `image` | Warn - `image` is required |
| AccordionDrawer | Has `content` | Change to `body` |

## Performance

- **Token cost**: ~300-500 tokens (Glob + Read first 40 lines)
- **Time**: Instant (local file read)
- **Prevents**: Failed MCP calls + retry overhead (~500 tokens saved)

## Usage Notes

- **Always validate**: Before every component authoring operation
- **Required fields**: Marked with `Yes` in the Fields table - warn if missing
- **Optional fields**: Can be omitted safely
- **Field name case**: Case-sensitive - `heading` != `Heading`
- **Doc not found**: If no doc file exists for the component, run `/generator-component-docs` to create it
