# FullWidth Component

## Purpose
FullWidth is a full-bleed container that intentionally breaks out of any parent max-width constraints to span the entire viewport. It wraps child components in a `FullWidthWrapper` that applies theme, max-width centering for inner content, and optional content alignment. An optional background image (with a separate mobile variant) can be layered behind the placeholder content via the `BackgroundImage` child component, which responds to viewport width changes using a debounced resize handler.

## Fields
| Field Name | Sitecore Type | Required | Description |
|------------|--------------|----------|-------------|
| `backgroundImage` | Image | No | Desktop background image displayed behind the placeholder content |
| `backgroundImageMobile` | Image | No | Mobile background image (falls back to `backgroundImage` on mobile if not set) |

## Placeholders
| Placeholder Name | Pattern | Allowed Components |
|-----------------|---------|-------------------|
| `fullwidth` | `placeholderGenerator(params, 'fullwidth')` | Any component |

The placeholder name is generated by `placeholderGenerator`, which appends any dynamic suffix from params.

## Props Interface
```typescript
import { ImageField } from '@sitecore-content-sdk/nextjs';

// From lib/hooks/useBackgroundImage
type BackgroundImageProps = {
  backgroundImage: ImageField;
  backgroundImageMobile: ImageField;
};

type FullWidthFieldsType = {
  fields: BackgroundImageProps;
};

type FullWidthProps = ComponentProps & FullWidthFieldsType;
```

## MCP Authoring Instructions

### Step 1: Add to Page
```javascript
await mcp__marketer_mcp__add_component_on_page({
  itemPath: "/sitecore/content/MySite/Home",
  componentName: "FullWidth",
  placeholderName: "main",
  dataSource: "/sitecore/content/MySite/Data/FullWidth/HeroBackground"
});
```

### Step 2: Set Background Image
```javascript
await mcp__marketer_mcp__update_component_fields({
  itemPath: "/sitecore/content/MySite/Data/FullWidth/HeroBackground",
  fields: {
    "backgroundImage": { "src": "/-/media/Project/Site/hero-bg.jpg", "alt": "Hero background" },
    "backgroundImageMobile": { "src": "/-/media/Project/Site/hero-bg-mobile.jpg", "alt": "Hero background mobile" }
  }
});
```
