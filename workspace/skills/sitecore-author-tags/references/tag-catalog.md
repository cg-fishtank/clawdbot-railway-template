## Lookup Instructions

When a tag ID is marked "🔍 Lookup needed":

1. Use `marketer_get_content_item_by_path` with the path from the table
2. Extract the `itemId` from the response
3. Update this file with the discovered ID
4. Replace "🔍 Lookup needed" with the GUID (UPPERCASE)

**Example:**
```javascript
const tagItem = await marketer_get_content_item_by_path({
  itemPath: "/sitecore/content/sites/main/Settings/Component Settings/Tags/Industries/Technology",
  language: "en"
});

// Update this file:
// Technology | `abc12345-...` | `/sitecore/.../Technology`
```

## SxaTags Field Format

Use pipe-separated GUIDs in braces (UPPERCASE):

**Single tag:**
```
{4DA2E751-BAD8-4F69-9C70-850504662FDD}
```

**Multiple tags:**
```
{4DA2E751-BAD8-4F69-9C70-850504662FDD}|{3AD028EF-640B-47C9-9DC4-8F15539A5D2E}
```

- Tags are hierarchically organized under category folders
